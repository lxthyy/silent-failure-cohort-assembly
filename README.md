# Silent failure in cohort assembly — analysis code and derived results

Version 2.09 · 12 November 2026 · Xin Li, Department of Laboratory Medicine, Taihe Hospital, Hubei University of Medicine

This repository accompanies the manuscript *The standard way of reading NHANES may be producing wrong numbers: twelve silent failure classes, a census of 286 modules, and a four-rule protocol*.

Nothing here redistributes participant-level data. The survey files are public and are downloaded by the reader; the three institutional laboratory databases cannot be shared (ethics approvals do not permit redistribution), and the code that touches them is included so that the logic can be inspected and re-run on data held under the same approvals.

## 3. Two things that will trip you up

1. **Two census scripts exist and only one is correct.** `A_nhanes_census.py` (uncalibrated) returns counts that do not match the manuscript. Use `A_nhanes_census_calibrated.py`.
2. **The module cache is already de-duplicated.** The 541 files in the raw download include 255 timestamped duplicate copies of the same modules; those were removed when the 286-file cache was assembled, so the census script reports `n_duplicate_copies_excluded = 0` when it runs on that cache. The manuscript's phrase "after excluding 255 timestamped duplicate copies" refers to the assembly of the cache, not to a step inside the analysis.

## 4. Running it

```bash
python -m pip install -r requirements.txt
python verify.py            # checks the shipped results against the reported numbers
```

`verify.py` needs no survey data and no institutional data: it reads `results/` and re-derives the headline figures (census anchors, the 4 × 5 detection matrix, the 0/150 boundary, 64 variables agreed, rounding denominators). It exits non-zero if any check fails.

To re-run the analyses themselves you need the public survey files. The extraction pipeline is distributed separately (version 2.09); it downloads SAS transport files from the NHANES public server and writes a flat file plus an audit report.

## 5. Boundaries

- The injection experiment uses a fixed seed per replicate; `results/B_headtohead.csv` carries the seed column, so every cell can be reproduced exactly.
- The institutional analyses are included for inspection only. `src/S4_synthetic_demo.py` runs the same check suite on a schema-identical synthetic dataset, so the logic can be exercised without the restricted data.
- Absolute risk, prevalence and mortality estimates are properties of the survey data and are not regenerated by `verify.py`.
